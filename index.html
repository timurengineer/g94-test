Git bilan tanishuv: rasmiy qo‘llanma

Git'ning rasmiy kirish qo‘llanmasi o‘zbekchada: loyihani git init bilan boshlash, o‘zgarishlarni commit qilish, branchlar bilan ishlash va Alice–Bob misolida hamkorlik. Seriyaning birinchi uch qismini bajargach, rasmiy manbani o‘z tilingizda o‘qish uchun.

Birinchi uch qismda Git'ni o‘rnatdik, sozladik va birinchi commitni qildik. Endi rasmiy qo‘llanmaning o‘zi — Git jamoasi yozgan kirish matni. Unda siz allaqachon ko‘rgan buyruqlar boshqa tomondan, manba muallifining tilida tushuntiriladi, oxirida esa ikki kishi bir loyihada qanday ishlashi ko‘rsatiladi.
